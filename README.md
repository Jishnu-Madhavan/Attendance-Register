### Face Recognition Based Online Attendance System

This project is a **Python-based attendance management system** that uses **face recognition technology** to automatically mark student attendance. The system captures faces using a webcam, recognizes them in real-time, and records attendance in a CSV file or database for easy tracking.

#### Key Features

- **Real-time face detection and recognition** using OpenCV and face\_recognition libraries
- **Automatic attendance marking** with date and time stamps
- **User-friendly interface** for managing attendance sessions
- **Easy to extend and customize** for schools, colleges, and organizations

#### Tech Stack

- Python
- OpenCV
- face\_recognition (dlib-based)
- Tkinter (optional GUI, if applicable)

#### How It Works

1. When a face is recognized, the system marks the person’s attendance along with the current timestamp.
2. Attendance data is automatically saved.
